Fitsy Design System

Hướng Trắng đen, ảnh làm chủ: khung giao diện đơn sắc để ảnh quần áo là thứ duy nhất có màu. Nguồn gốc của mọi giá trị là styles.css. Bật Dev Mode rồi bấm vào một component để xem thuộc tính và token; dùng Copy as prompt để nhờ AI dựng component đó trong code.
